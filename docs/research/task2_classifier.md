# Task 2 classifier baseline

Provisional CNN: three convolution/ReLU/average-pooling stages (16/32/64 channels), global average pooling, dropout0.1, four logits. Cross entropy consumes logits; softmax will expose probabilities at inference. This small from-scratch CNN is a starting hypothesis for detecting image corruption patterns, not an Optuna-selected final model. Global pooling reduces parameters but may miss localized occlusions; validation must establish this limitation. Larger CNNs or pretrained backbones are alternatives requiring measured justification, not rejected on assumed performance.

Each shuffled source image supplies clean/salt/blur/occlusion examples with independent runtime corruption seeds. A batch of32 uses eight source images and eight examples per class. Final smaller batches also remain balanced. Every source is visited once per epoch, so one full epoch contains11,776 examples. Shared image content across classes reduces content/class confounding, but examples within a batch are correlated. This is a deliberate alternative to probabilistic class sampling, which does not guarantee balance.

Adam LR0.001, weight decay0.0001, ten epochs, seed42. These settings are provisional. Required classifier Optuna search over LR, batch size, channels, dropout and weight decay remains pending. Three independent specialists, specialist tuning, oracle/predicted routing, test evaluation and ONNX export also remain pending.

Use notebooks/task2_classifier_colab.ipynb after pushing implementation. Outputs live in MyDrive/GenAI_A1/task2-classifier. Source/data signatures, optimizer/RNG/cursor state enable batch resume using last.pt. Only one run per folder. Soft time budgets cannot guarantee protection against abrupt Colab termination; periodic checkpoints limit loss. No existing Task1 files were changed.

Validation uses all7,360 fixed cases: clean736, each corrupted class2,208. Overall accuracy reflects these unequal supports; macro precision/recall/F1 weight classes equally. Best checkpoint uses macro F1. Confusion rows are true labels, columns predictions, normalized by row support. Undefined precision/recall is assigned zero. Per-condition/severity correct/count is also recorded. Report validation honestly; official test remains untouched until model selection is frozen. Route probabilities and calibration are not established by accuracy alone.
