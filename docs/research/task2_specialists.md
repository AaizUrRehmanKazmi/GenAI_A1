# Independent Task 2 specialists

Implemented three independently initialized/restored instances of the no-skip 16×16 autoencoder. This architecture is a provisional reuse of the strongest Task1 candidate, not a Task2 Optuna result. Each instance has its own parameters/optimizer and sees only its condition, with clean reconstruction targets. Effective seeds are base42 plus101/202/303 for salt/blur/occlusion. No Task1 trained weights are loaded. LR0.000711606, batch16, alpha0.5, latent32 and dropout0 are starting settings only.

A specialist epoch visits each of2,944 training images once with fresh condition-specific corruption. Validation filters the unchanged manifest to2,208 cases for that condition (736×3 severities), equally weighting severities. Best weights minimize that specialist's reconstruction loss. Input L1/SSIM are recorded per severity so model improvement is not inferred from training loss alone. Debug subsets are explicitly labeled. Official test images remain unused.

Use notebooks/task2_specialists_colab.ipynb after pushing the implementation, when GPU becomes available. Start a five-epoch pilot for salt, then blur and occlusion separately. Outputs: MyDrive/GenAI_A1/task2-specialists/{salt,blur,occlusion}. Each has independent last.pt/best.pt, source/config fingerprints, RNG/optimizer/cursor, history, preview and MLflow logs. Removing --stop-after-epoch continues toward20 unchanged total epochs. Do not modify source/config or switch condition when resuming. Old Task1/classifier sources are unchanged.

HardRouter selects the predicted argmax branch or accepts supplied oracle labels. Class order is clean/salt/blur/occlusion. The classifier exposes softmax probabilities in predicted mode; oracle mode never calls it. Output starts as an exact clone of input; only selected corrupted rows are processed by their expert. Call eval() for inference. Distinct expert objects/parameter ownership are enforced. This tensor router is not yet an ONNX export implementation or a complete checkpoint-loading/evaluation application.

Why this baseline: independent specialization tests whether a shared universal task caused compromise. Identical architecture helps comparison; different seeds create independent initial states. It does not guarantee blur quality, and existing clean-detail degradation motivates the identity path. Predicted-clean protection still depends on correct classification. Larger models, skip-based architectures and different bottlenecks require separate evidence and assignment review; they have not been ruled out experimentally here.

Remaining: shared specialist Optuna search including channel configuration, LR, bottleneck size, batch size and alpha; classifier tuning; checkpoint bundle loading and full oracle-vs-predicted validation reports; routing failure examples; frozen final test evaluation; ONNX and UI integration. Do not label Task2 complete based on these smoke checks.
