# Task 2 Optuna protocol

Run notebooks/task2_optuna_kaggle.ipynb, mode classifier first. Use new task2-optuna-{mode} folders; previous baselines and fingerprinted trainers remain unchanged. Each study has eight total trials and five screening epochs using full train/validation splits. Trial0 repeats baseline settings. First four completed observations form startup exploration, followed by TPE proposals. No pruning; short-budget winners still require full-budget confirmation. Separate condition searches are implemented rather than a shared architecture search: each specialist may select different settings, at greater compute cost (24 specialist trials). Run sequentially and review compute availability.

Classifier space: LR log-uniform0.0003–0.003, batch16/32/64 (all divisible by4), channels [16,32,32]/[16,32,64]/[32,64,128], dropout0/.1/.2, weight decay log-uniform1e-5–1e-3. Rank final screening epoch by1-macroF1; inspect clean recall and clean/blur confusion rather than overall accuracy alone. A separate train_classifier_search copy adds pause-after-epoch while preserving target10 and original classifier checkpoint compatibility. New search runs must resume using this trainer, not the old one.

Specialist space: LR log-uniform0.0002–0.002, batch8/16, latent channels16/32/64, encoder channels [16,32,64,128]/[32,64,128,256], alpha .5/.65/.8. Dropout remains0. Same compressed16×16 no-skip architecture family. Rank final epoch by fixed0.8*L1+0.2*(1-SSIM), NOT variable-alpha val_loss. Each trial is independently initialized and trained only on its assigned condition. Retain target20 for continuation. Parameter count/compute differ across channel settings; equal epochs do not imply equal updates or wall time.

Source/config/data/version signatures protect search resume. JSON study records are atomically replaced and completed trials reconstruct Optuna history; seeded proposals use42+trial number. Keep only one process per study. Backup whole output folder before ending Kaggle. A stop before the first checkpoint may require preserving/renaming the partial trial folder; failures are not silently scored. Eight trials over five dimensions are exploratory, not an exhaustive optimum or evidence that TPE dominates random/grid search.

Review classifier leaderboard first, then blur, salt and occlusion as budgets permit. Compare screening candidates against baseline at the same screening budget. Continue selected trials to full10/20 epochs, inspect restoration input baselines and routing metrics, then rerun the same routed validation comparison. Do not modify total epochs/config or source on resume. selected_config.yaml is provisional. Test data, ONNX and final deployment remain later work.
